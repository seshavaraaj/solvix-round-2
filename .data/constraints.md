# Project Constraints

These limits apply to every design, tooling, and deployment decision in this project.

## 1. Zero budget

- The project has no money to spend.
- Use only free or open-source tools, libraries, datasets, and services.
- If a service is paid, use it only on a free tier that needs no payment method, or replace it with an open-source alternative.

## 2. Cloud hosting: Render

- Deploy all cloud-hosted parts on [Render](https://render.com).
- Stay within the limits of Render's free tier. For example, free web services sleep when idle and have limited compute and storage.
